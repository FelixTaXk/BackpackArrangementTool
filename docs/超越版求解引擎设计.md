# 超越版求解引擎 + 游戏主题 UX 设计文档

## 总览

在保留现有 DFS 全装引擎（[js/solver-worker.js](file:///c:/Users/ASUS/Desktop/%E8%83%8C%E5%8C%85%E6%8E%92%E5%88%97%E5%B7%A5%E5%85%B7/js/solver-worker.js)）字节级不动的前提下，旁路新增"超越版"元启发式引擎。新引擎融合并超越竞品的全部关键技术，且在七个维度上更先进：

| 维度 | 竞品 | 本设计 |
|---|---|---|
| 邻域选择 | 固定 45/30/25 | **ALNS 自适应算子轮盘赌**（段式记分动态调权） |
| 并行协作 | 岛模型中心广播 | **并行回火 Replica Exchange**（对偶准则交换，去中心化，可降级） |
| 增量评分 | 重算受影响件 | **成对加性 CSR 对表**，delta 仅 O(形状周长)，戳去重零分配 |
| 位板 | Int16Array 扫格 | **Uint32Array(L) 位板**（L=2，42 格），冲突一条 AND |
| LNS 上界 | 分数背包+连通空区 | 分数背包+**配对感知加成松弛**+连通空区（零 BigInt 重写） |
| 目标语义 | 复合分近似填满优先 | **真字典序复核闸门**（complete>总属性>手动向量>默认向量>邻接>件数>面积） |
| 可复现/兜底 | 无 | **种子 RNG 可复现** + **DFS Portfolio 成员**保完整装入完备性 |

正确性架构原则：**热路径快算、晋级全算**——SA 内部用标量能量驱动搜索，但任何对外 incumbent 必须经共享全量评估器重算 + 主线程 `compareSolverBest`（[solver.js#L186-203](file:///c:/Users/ASUS/Desktop/%E8%83%8C%E5%8C%85%E6%8E%92%E5%88%97%E5%B7%A5%E5%85%B7/js/solver.js#L186-L203)）真字典序复核。加成语义严格按本项目（provider/self 分项 stats×rates、不限属性），不移植竞品评分。

## 核心数据结构（engine-encoding.js）

位板：`Uint32Array(L)`，L=ceil(W*H/32)=2；冲突 `(occ[k]&p[k])===0 ∀k`。
Placement SoA：`plMask/plNbr Uint32Array(P*L)`、`plItem Uint16Array`、`plArea Uint8Array`、`plPerimOff/Len`+`perimCells Uint8Array`（外圈格索引扁平表）、`plCellsOff/Len`+`cellsFlat`。
Item SoA：`itemValue/itemStats(I*K)/itemRates(I*K) Float64Array`、`itemKind Uint8Array(0 none/1 provider/2 self)`、`itemManual Int16Array`、`itemTier Int8Array`、`itemPlOff/Len`。
**CSR 对表**（成对加性地基，仅存几何可相邻的 placement 对）：`adjOff Uint32Array(P+1)`、`adjPeer Uint32Array(Σdeg)`、`adjBonus Float64Array(Σdeg)`（=potentialPairBonus 精确值，语义按 [solver-worker.js#L107-117](file:///c:/Users/ASUS/Desktop/%E8%83%8C%E5%8C%85%E6%8E%92%E5%88%97%E5%B7%A5%E5%85%B7/js/solver-worker.js#L107-L117) 重写）、`adjMan/adjDef Uint32Array(Σdeg)`（位压缩优先级向量增量，权重对齐 L148-149 的 1e8/1e5）。规模：deg≤周长≤12，P≤1800 时 Σdeg≤2 万，<500KB。
运行态（预分配、稳态零分配）：`occ Uint32Array(L)`、`cellOwner Int16Array(42)`、`solPl Int32Array(I)`、`touchStamp Int32Array(I)`+纪元、`energyParts Float64Array(8)`、`bestSol/bestParts` 常驻副本、xorshift128+ 种子 RNG。

## 增量 delta 公式（engine-worker.js 热路径）

```
deltaFor(pIdx, sign):            // O(周长)，戳去重同件多格相邻
  stampEpoch++
  for e in adj 区间(pIdx):
    q=adjPeer[e]; if solPl[plItem[q]]<0 或 同件已戳: continue
    戳记; dAdj+=sign; dBonus+=sign*adjBonus[e]; dManW/dDefW+=sign*解码(adjMan/adjDef[e])
applyMove(it,pNew): 先 undoDelta(solPl[it])，再位板 OR+cellOwner 写+addDelta(pNew)；回滚=反向执行
```
标量能量（量级隔离，间隔按各层可证上界设定）：`E = -(1e12*complete + totalScore + 1e8*Σmanual加权 + 1e5*Σdefault加权 + 10*adj + items + 1e-3*area)`。

## SA+ALNS 主循环

初始解：价值密度+rng 扰动贪心；Portfolio 下接收 DFS incumbent 作种子（orchestrator 解码广播）。
ALNS：算子表 `relocate / moveGreedy / swapPair / removeInsert / shuffleRegion`（一期）+ `lnsSmall/lnsBig`（二期注册，框架零改动扩展）；每 SEGMENT=256 迭代按 `w'=w*(1-ρ)+ρ*segScore/max(1,segCount)`（ρ=0.1，σ=33/9/1，钳制 [0.1,10]）更新，轮盘赌前缀和。
接受：Metropolis `rng()<expTable[tempBin][-ΔE 分档]`（exp 查找表免 Math.exp）；温度几何分层 `T_i=T0*0.85^i`，T0=0.03*|初始分|+1，4 周期重热。
晋级：`E` 超最优时从 solPl 重建 placements → 共享 `scoreEvaluateConcrete` 全量重算 → orchestrator 重建序列化 best → 走现有 incumbent 路径实时渲染。

## 并行回火协议（engine-orchestrator.js）

默认档（file:// 兼容）：每 2048 迭代或 50ms，Worker 发 `{type:'swap-req', i, E, sol:Transferable Int32Array}` 后**不等待继续迭代**；主线程 broker 对相邻温度对 (i,i+1) 奇偶轮按 `min(1,exp((βk-βk+1)(Ek+1-Ek)))` 配对，transfer 回发；接收方在 checkMessages 点 O(Σarea+Σdeg) 重建状态。通信 ≤168B/次，开销 <2%。增强档：检测 `crossOriginIsolated` 启用 SharedArrayBuffer+Atomics（仅 HTTP+COOP/COEP）。隐藏开关可整体禁用（退化为温度分层 Portfolio，正确性不受影响）。

## 二期：LNS+配对感知上界

摧毁：random / worst（边际贡献排序）/ region（cellOwner BFS 连通域，零 BigInt 格子 CSR 重写 freeComponents）；k=2~10 自适应+失败缓存。修复：受限 DFS anytime 500ms 分片；上界 = 当前分 + 分数背包（密度=(value+最大潜在邻接)/area）+ **配对松弛**（remaining 各件取 potMat 最大可达项之和）+ 连通空区剔除；UB≤incumbent 即剪枝。

## 分期与任务分解

**期 0 脚手架**（行为零变化）：engineMode 下拉+persistence 可选字段+script 登记+工厂选择行（恒 legacy）。验证：配置往返、旧存档兼容、输出与现状逐字段一致。
**期 1 核心引擎**：score-shared → engine-encoding → engine-worker（SA+ALNS+增量+种子 RNG）→ orchestrator（Portfolio：fast 档恒 legacy；hybrid=全 SA；auto=1 DFS+K-1 SA）+ 回火开关。依赖序：encoding 依赖 score-shared；worker 依赖前两者；orchestrator 依赖 worker。验证：契约键集 diff（legacy vs sa 导出 JSON 键一致）、固定种子复现、取消/terminate 无残留 Blob URL、控制台零错误、legacy 档 bit-identical。
**期 2 LNS**：lns 模块+配对上界+ALNS 注册。验证：满盘僵局用例（总面积≈42）解质量对比一期。
**期 3 对接放量**：statusBox 增 SA 行（温度/接受率/算子 Top3，追加不改旧字段）、默认 auto、docs 手工回归清单、SAB 增强档、20×20 扩展路径（位板 L 循环化已在一期内置）。
**期 4 主题 UX**：以期 0-3 功能稳定为前提独立交付，与算法改动解耦、可单独回退。

## 风险与缓解

- **语义漂移**：score-shared 单一真源+黄金自测+固定种子双引擎 diff 回归；晋级全量重算闸门。
- **标量能量碰撞字典序**：量级间隔按可证上界设定；incumbent 必过真字典序复核器。
- **GC 回归**：热路径禁对象分配（TypedArray+戳+exp 表+共享返回对象），验收含 allocation profiling。
- **Worker 生命周期**：新 Worker 进同一 solverWorkers 数组，cleanup/cancel/onerror 零改动覆盖；`_blobUrl` 必挂。
- **file:// 无 SAB**：双档降级，默认 broker 全场景可用。
- **旧引擎回归**：旧文件字节级不动，legacy 档天然 bit-identical；fast 档恒 legacy。
- **主题 UX 可读性**：书法字体仅用于标题/牌匾，正文与数字用圆黑+等宽数字；对比度 AA 门禁；风味术语一律配功能副标题。

## Rejected Alternatives

- **逐字移植竞品代码**：无许可声明有侵权风险，且加成语义（仅同属性、简化比例）与本项目不符会算错——读思路自实现。
- **一期即重构旧 Worker 接共享层**：1018 行 Blob 单函数重构爆炸半径大；改为旧引擎不动、新引擎独立共享层+diff 回归，统一重构留作可选后续。
- **SharedArrayBuffer 单档**：file:// 双击场景不可用，必须 broker 降级档。
- **复合分取代字典序**：破坏"完整装入优先+优先级向量"产品承诺；标量能量仅驱动搜索，排序由复核器兜底。
- **纯 SA 无 DFS Portfolio**：丢失完整装入完备性与可证穷尽；DFS 作成员兼种子源。
- **暗色科技风/卡牌拟态等通用主题**：用户明确要贴合《我要当老祖》世界观；游戏实机截图已提供权威视觉依据（宣纸木牌+水墨书法），通用主题无法形成"同款工具"的沉浸感。
- **引入网络字体/图片资源**：破坏 file:// 离线可用性；书法感用本地楷体栈+CSS 描边模拟，纹样用纯 CSS 伪元素绘制。
