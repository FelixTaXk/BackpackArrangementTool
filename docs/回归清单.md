## a) legacy 档结果与基线一致

1. file:// 打开 index.html；确认「求解引擎」下拉默认为「混合 Portfolio」（期 3 新默认，见 c）。
2. 手工切回「经典精确搜索」，按 e2e 基线流程（step3 筛选金+红 → step4 组清单）重建同一清单。
3. 深度档、默认上限（2,500,000 节点 / 20,000 ms）、关闭并行，点击「搜索更优摆放解」。
4. 预期：结果网格、六项统计、分项统计、状态区文本与 e2e-step5-solver-result.png / engine-legacy-result.png 一致；**状态区不出现任何「模拟退火」字样**（SA 摘要段不得追加）；控制台零错误。

## b) fast 档恒旧 DFS

1. 同清单切「快速（最多 3 秒）」档，引擎下拉任意取值（auto/hybrid 均可）。
2. 求解。预期：走 legacy DFS（状态区无 SA 行、无 SA 摘要；节点上限被压到 ≤350,000、时间 ≤3,000 ms）；输出格式与期 2 前逐字一致。
3. 依据：engOrchCreateWorkers 中 `useSa = searchMode !== 'fast' && engineMode !== 'legacy'` 铁律未动。

## c) auto 档默认启用与 SA 行

1. **新装/清空存档**（DevTools → Application → Local Storage 删除 `bagSolverConfig`）后刷新页面：引擎下拉应为「混合 Portfolio」（selected=auto）。
2. 深度档、勾选并行搜索、Worker 数量 ≥3，求解 auto 档。
3. 实时态预期：statusBox 出现 SA 行组——模拟退火温度、接受率 %、迭代速率（万/秒）、重热次数、算子权重 Top3（名称+权重）及 lnsSmall/lnsBig 小字说明；每 500 ms 刷新。
4. 终态预期：renderStats 原文之后追加「模拟退火（SA）摘要：N 个 SA Worker 参与（主线程 broker 回火）…」三行。
5. 结果质量对照 engine-auto-result.png / engine-hybrid-result.png（绝对分随种子波动，口径一致即可：complete/总属性/邻接结构与基线同量级）。
6. **K=1 退化纯 DFS**：auto 档 + 取消勾选并行（或 Worker=1）求解。预期：只有 1 个 DFS Worker（saCount=0），状态区无 SA 行、无 SA 摘要，行为等同 legacy。

## d) 老存档读档跟随存档值

1. 先在控制台构造老存档：`localStorage.setItem('bagSolverConfig', JSON.stringify({schemaVersion:2, W:7, H:6, active:[...], searchMode:'deep', nodeLimit:2500000, timeLimit:20000, inventory:[]}))`（**不含 engineMode 字段**）。
2. 点「读取配置」。预期：引擎下拉为「经典精确搜索」（legacy 回退，保守决策；见 persistence.js applySharedSettings 注释与 docs/进度说明.md 期 3 小节），非页面默认 auto。
3. 再保存一次（此时含 engineMode）→ 手工把下拉切到 hybrid → 保存 → 切回 legacy → 读取。预期：读回 hybrid（已存值跟随存档）。
4. 读档后清单恢复对照 e2e-step6-restored-list.png。

## f) file:// 下 SAB 永不启用、broker 正常

1. file:// 直接打开（默认使用方式）。控制台执行 `engOrchSabAvailable()` → 预期 `false`（crossOriginIsolated 在 file:// 恒 false）。
2. auto/hybrid 档 + 并行 ≥2 求解：控制台零错误；回火经 broker 消息对正常交换（终态摘要显示「主线程 broker 回火」）；结果质量正常。

## g) http(s)+COOP/COEP 下 SAB 档启用

1. 本地起服务并加跨源隔离头（PowerShell 示例，任选其一）：

```powershell
# 方式一：Node 单文件静态服务（临时写入任意目录执行）
node -e "require('http').createServer((q,s)=>{const fs=require('fs'),p=require('path'),f=require('url').parse(q.url).pathname==='/'?'index.html':require('url').parse(q.url).pathname.slice(1);fs.readFile(p.join(process.cwd(),f),(e,d)=>{if(e){s.writeHead(404);s.end('404')}else{s.writeHead(200,{'Cross-Origin-Opener-Policy':'same-origin','Cross-Origin-Embedder-Policy':'require-corp','Content-Type':f.endsWith('.js')?'text/javascript; charset=utf-8':f.endsWith('.html')?'text/html; charset=utf-8':'application/octet-stream'});s.end(d)}})}).listen(8080)"
```

```powershell
# 方式二：已装 npx 可用
npx --yes serve -l 8080   # 注意：serve 默认不加 COOP/COEP，需改用带 --config 或反代加头；推荐方式一
```

2. 浏览器打开 http://localhost:8080/，控制台执行 `crossOriginIsolated` → 预期 `true`；`engOrchSabAvailable()` → `true`。
3. hybrid 或 auto 档 + 并行 ≥3 求解：控制台零错误；终态摘要显示「SAB 直连回火通道」；结果质量与 broker 档同口径（同温度分层 Portfolio，绝对分随机波动正常）。
4. 同种子同档 K=1 复现性不受影响（SAB 通道仅 saCount≥2 时建立）。

## h) 三个隐藏开关

均先在控制台设置再求解（设置后刷新会丢失，属预期）：

| 开关 | 设置 | 预期 |
|---|---|---|
| `window.__ENGINE_TEMPERING_OFF__ = true` | auto/hybrid 并行求解 | 回火整体禁用（broker 档回发原 sol；SAB 不建立，因 temperingOn=false）；求解正常完成，无错误 |
| `window.__ENGINE_LNS_ON__ = true` | 任意 SA 档求解 | init meta lnsEnabled=true，op7/op8 真实执行（期 2 已验收链路，复测不报错即可） |
| `window.__ENGINE_SAB_OFF__ = true` | g) 的 COEP 环境下并行求解 | `engOrchSabAvailable()` 返回 false，强制走 broker；终态摘要显示「主线程 broker 回火」 |

## i) 控制台零错误、取消求解无残留

1. 全流程（a~h）各步骤控制台无 error/warning（数据库校验 warn 除外，本次无新增数据）。
2. 求解中途多次点击「停止计算」：状态区显示「计算已由用户停止…」；Worker 全部 terminate（`solverWorkers.length===0`）；blob URL 已 revoke；再次求解正常；无定时器泄漏（statusBox 计时停止增长）。
3. SA 档与 legacy 档交替取消各 ≥2 次。

## j) G3 迭代速率浏览器实测 ≥15 万/秒

1. auto/hybrid 档求解，观察 statusBox「模拟退火迭代速率」行（或 progress 消息 saItersPerSec）。
2. 预期：≥15 万/秒（期 1 浏览器基线 19.4 万/秒）。期 3 新增 saOpTop3 仅每 500 ms 做一次 9 元素排序，开销可忽略。
3. 注意：vm/harness 沙箱时钟口径不可信（期 2 G3 SKIP 原因），必须以真实浏览器为准。

## 附：20×20 扩展路径（文档化）

位板 L 循环（逐行位掩码推进）已在 engine-encoding.js 内置为 W/H 参数化结构，SA 侧全部表结构（occ/cellOwner/邻接 CSR/摆放枚举）按 `m.W*m.H`、`m.L`、`m.I` 动态分配，无 7×6 硬编码逻辑。**扩展到 20×20（或任意 W×H）只需：**

1. `js/state.js` 初始 W/H 常量（当前 7/6）；
2. 校验与钳制处：`index.html` 宽高输入框 `max` 属性、`js/ui-space.js` applySize 的 `Math.min(7, ...)/Math.min(6, ...)`、`js/persistence.js` applySharedSettings 的同式钳制、`js/config.js` 形状坐标范围校验（当前 `r<=5 && c<=6`）；
3. DFS 旧引擎（solver-worker.js）若同步放开，需复核其位板枚举性能（本期不动，铁律零改动）。

无代码结构改动，无引擎层改动。
