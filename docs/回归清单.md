# 求解引擎 · 回归清单

> 适用版本：纯 SA 引擎（老 DFS 引擎已退役并删除，`engineMode` 下拉已移除）。file:// 全程兼容。
> 铁律回顾：ui-result.js / engine-worker.js 冻结（字节级零改动）；新功能一律只加法、RNG 基线天然保护。

## 0. 界面速览（本清单覆盖的功能入口）

- 求解设置：搜索档位（快速/深度）、加成聚焦、节点/时间上限、启用百分比相邻加成、并行搜索 + Worker 数量、权重口径（默认/自定义 + 预设）。
- 法宝库：属性筛选罗盘（8 属性，默认金）+ 种类筛选（随属性动态）+ 品质行内下拉。
- 已有法宝清单：编号/品质/邻接优先级/长老星级（红品质）。
- 求解结果：摆放网格（格内带属性小徽章）+ 统计面板（实际总属性横幅 + 分项）+ 方案暂存三槽。

## a) 求解基础流程

1. file:// 打开 index.html，先选空间（宽高默认 7×6，全解锁）。
2. 法宝库属性筛选选「金」→ 种类筛选选某一种类（或「全部」）→ 某行「品质」列选品质 → 「添加」入清单。
3. 已有法宝清单可填「邻接优先级」（1 最高）与红品质「长老星级」。
4. 点「搜索更优摆放解」。预期：statusBox 出现 SA 实时行（温度/接受率/迭代速率/重热/Top3，每 500 ms 刷新）；终态追加「模拟退火（SA）摘要：N SA Worker 参与（主线程 broker 回火 / 未启用回火（单 SA））」。
5. 结果网格按品质着色，每个法宝形状左上角首格有属性字符徽章（颜色与法宝库属性一致，含邪=黑）。

## b) 快速/深度档与并行

1. 「快速」档：时间上限压到 ≤3,000 ms、节点上限 ≤350,000（statusBox 首行提示生效值）；引擎仍是 SA。
2. 「深度」档：使用自定义上限（默认节点 2,500,000 / 时间 20,000 ms）。
3. 勾选「并行搜索」+ Worker≥2：多 SA 回火交换，终态摘要显示 Worker 数；「并行搜索」默认关闭 = 单 Worker（摘要「未启用回火（单 SA）」）。
4. 结果质量：complete/总属性/邻接结构合理；并行结果 ≥ 单 Worker。

## c) 加成与权重口径

1. 勾选「启用百分比相邻加成」：相邻同属性法宝产生 provider/self 加成事件；统计面板分项含加成值。
2. 加成聚焦：选某属性 → 只优化该属性加成（需先勾选百分比加成，否则 alert 拦截）。
3. 权重口径「自定义」：八项权重（攻/防/生命/伤害/暴击伤害/治疗效果/护盾值/汲取）与预设钮；权重只作用于基础计价，加成按原价；0 按 0.01 保底。
4. 权重激活时终态追加「属性权重口径」行；横幅/分项呈实际总属性（Σ真实基础 + Σ真实加成）。

## d) 存档往返与结果导出

1. 保存配置 → 刷新 → 读取：空间/求解设置/清单/权重口径完整恢复（schemaVersion=2）。
2. 老存档（旧版含已废弃 `engineMode`/不含权重键）读档：空间与求解设置保留，清单按 id 重建，缺失 id 提示跳过。
3. 导出结果 JSON：含 best/placements/solverMeta（engine='sa'）等完整字段。

## e) file:// 与 SAB

1. file:// 打开（默认方式）：控制台执行 `engOrchSabAvailable()` → `false`（crossOriginIsolated 恒 false），回火走主线程 broker。
2. 并行 ≥2 求解：终态摘要「主线程 broker 回火」；结果正常。
3. http(s)+COOP/COEP 下：`engOrchSabAvailable()` → `true`，终态摘要「SAB 直连回火通道」。

## f) 三个隐藏开关（控制台设置后求解）

| 开关 | 预期 |
|---|---|
| `window.__ENGINE_TEMPERING_OFF__ = true` | 回火整体禁用，求解正常 |
| `window.__ENGINE_LNS_ON__ = true` | init meta lnsEnabled=true，LNS 算子真实执行 |
| `window.__ENGINE_SAB_OFF__ = true` | SAB 禁用，强制走 broker |

## g) 控制台零错误、取消无残留

1. 各步骤控制台无 error/warning（数据库校验 warn 除外）。
2. 求解中途「停止计算」：状态区显示停止文案；`solverWorkers.length===0`；blob URL 已 revoke；可再次求解；定时器无泄漏。
3. 迭代速率：≥15 万/秒（以真实浏览器为准，沙箱时钟口径不可信）。
