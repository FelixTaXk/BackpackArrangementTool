# 法宝数据 Excel 格式说明

本文档用于说明「背包排列工具」所需法宝属性数据的 Excel 整理格式。请按下述格式整理法宝的属性数据并提供给我们，我们会将其转换为工具的内置数据库。

**背景说明**：工具会在 7×6 的背包网格中摆放法宝，以最大化属性总和。法宝体系为 7 种属性（金、木、水、火、土、雷、体）× 5 种品质（绿、蓝、紫、金、红）。

每件法宝包含以下信息：

- **形状**：占用格子的布局
- **基础属性**：可含多个项目（伤害、生命值、防御、攻击等）
- **加成模式**：提升相邻法宝（provider）/ 提升自己（self）/ 无（none）
- **分项加成率%**：每个加成项目可以有不同的加成率

**加成计算规则**：

- **提升相邻（provider）模式**：对每个相邻法宝，贡献「相邻法宝对应项目基础值 × 加成率%」。
- **提升自己（self）模式**：每相邻一个不同法宝，给自身增加「自身对应项目基础值 × 加成率%」。

---

## 一、三表结构（长表设计）

Excel 共包含 3 个 Sheet，均采用「长表」设计：**新增加成项目或基础属性项目时，只需增加行，无需修改列结构**。

### Sheet1「法宝主表」

| 列名 | 说明 |
| --- | --- |
| 属性 | 法宝属性（金/木/水/火/土/雷/体） |
| 品质 | 法宝品质（绿/蓝/紫/金/红） |
| 名称 | 法宝名称（全局唯一） |
| 形状 | 形状文本（填写规范见下文） |
| 加成模式 | 提升自己 / 提升相邻 / 无 |
| 邻接优先级档 | 数字，可留空 |

示例：

| 属性 | 品质 | 名称 | 形状 | 加成模式 | 邻接优先级档 |
| --- | --- | --- | --- | --- | --- |
| 金 | 红 | 诛仙剑 | ##.（换行）.## | 提升自己 | 1 |
| 木 | 紫 | 青木葫芦 | #（换行）#（换行）# | 提升相邻 | 2 |
| 体 | 蓝 | 玄武甲 | ## | 无 | |
| 水 | 绿 | 净水瓶 | # | 提升相邻 | |

### Sheet2「基础属性表」

一行填写一个属性项目，同一法宝有多个项目时占多行。

| 列名 | 说明 |
| --- | --- |
| 法宝名称 | 必须与 Sheet1 名称完全一致 |
| 属性项目 | 如 伤害、生命值、防御、攻击 等 |
| 基础值 | 数字 |

示例：

| 法宝名称 | 属性项目 | 基础值 |
| --- | --- | --- |
| 诛仙剑 | 伤害 | 64 |
| 诛仙剑 | 生命值 | 120 |
| 青木葫芦 | 攻击 | 45 |
| 玄武甲 | 防御 | 38 |
| 玄武甲 | 生命值 | 90 |
| 净水瓶 | 生命值 | 30 |

### Sheet3「加成项目表」

一行填写一个加成项目，每个加成项目可以有各自不同的加成率。

| 列名 | 说明 |
| --- | --- | --- |
| 法宝名称 | 必须与 Sheet1 名称完全一致 |
| 加成项目 | 该法宝加成的属性项目 |
| 加成率% | 数字，百分比数值（如 40 表示 40%） |

示例：

| 法宝名称 | 加成项目 | 加成率% |
| --- | --- | --- |
| 诛仙剑 | 伤害 | 40 |
| 诛仙剑 | 生命值 | 20 |
| 青木葫芦 | 攻击 | 30 |
| 净水瓶 | 生命值 | 25 |

## 二、形状填写规范

在 Sheet1「形状」单元格内，使用**多行文本**描述形状：

- `#` 表示占用的格子
- `.` 表示空格

例如三格 L 形，写成 `##.` 换行 `.##`：

```text
##.
.##
```

要求：

- 形状最大为 **7 列 × 6 行**（与背包网格一致）。
- 所有 `#` 格子必须**相互连通**（上下左右相邻连成一体）。
- 单元格内需保留换行（Excel 中可用 Alt+Enter 输入换行）。

更多示例：

```text
#      （单格）
```

```text
###    （横排三格）
```

```text
##
##     （2×2 方块）
```

## 三、字段约束

| 字段 | 约束 |
| --- | --- |
| 属性 | 限 7 选 1：金、木、水、火、土、雷、体 |
| 品质 | 限 5 选 1：绿、蓝、紫、金、红 |
| 加成模式 | 限 3 选 1：提升自己、提升相邻、无 |
| 名称 | 必须全局唯一，不可重复 |
| 加成率% | 数字（百分比数值，如 40 表示 40%） |

---

## 四、注意事项

1. 加成模式为「无」的法宝，Sheet3「加成项目表」中**可以不填**该法宝。
2. 「邻接优先级档」数字**越小越优先**；可留空，留空时使用默认规则。
3. 同一法宝在 Sheet2、Sheet3 中填写的名称，必须与 Sheet1 中的名称**完全一致**（包括空格与标点）。

## 五、完整示例：诛仙剑

以下是一件完整法宝在三个表中的填写方式，贯穿三表：

**法宝设定**：诛仙剑，金属性，红品质，L 形 3 格，提升自己（self）模式；基础属性：伤害 64、生命值 120；加成项目：伤害 40%、生命值 20%。

**Sheet1「法宝主表」**：

| 属性 | 品质 | 名称 | 形状 | 加成模式 | 邻接优先级档 |
| --- | --- | --- | --- | --- | --- |
| 金 | 红 | 诛仙剑 | ##.（换行）.## | 提升自己 | 1 |

形状在单元格内的实际内容：

```text
##.
.##
```

**Sheet2「基础属性表」**：

| 法宝名称 | 属性项目 | 基础值 |
| --- | --- | --- |
| 诛仙剑 | 伤害 | 64 |
| 诛仙剑 | 生命值 | 120 |

**Sheet3「加成项目表」**：

| 法宝名称 | 加成项目 | 加成率% |
| --- | --- | --- |
| 诛仙剑 | 伤害 | 40 |
| 诛仙剑 | 生命值 | 20 |

**效果说明**（提升自己模式）：诛仙剑每相邻一个不同的法宝，就给自己增加「自身基础值 × 加成率%」，即每有一个相邻法宝：伤害 +64×40% = 25.6，生命值 +120×20% = 24。
